# 홈서버(Rocky Linux 8 + 기존 Apache) 설치 가이드

```
https://내이름.duckdns.org       → 운영 (main 브랜치)
https://내이름-test.duckdns.org  → 테스트 (develop 브랜치)
```

## ⚡ 빠른 설치 (자동 스크립트)
Docker 설치 후, 서버에서 두 줄이면 끝나요. (DuckDNS 주소 2개 + 토큰 준비)
```bash
git clone -b develop https://github.com/ldw9571/blog-assist-program.git /opt/blog/test
bash /opt/blog/test/deploy/install.sh
```
- 인증서가 실패하면 공유기 포트포워딩(80, 443) 후: `bash /opt/blog/test/deploy/install.sh cert`
- 아래는 스크립트가 하는 일을 손으로 할 때의 순서예요.

## 0. 준비
- DuckDNS(https://www.duckdns.org) 로그인 → 주소 2개 추가 (운영용, 테스트용) → token 메모
- 공유기 외부 IP = 네이버 "내 아이피" 인지 확인

## 1. Docker 설치 (root)
```bash
dnf -y install dnf-plugins-core git
dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
dnf -y install docker-ce docker-ce-cli containerd.io docker-compose-plugin --allowerasing
systemctl enable --now docker
docker --version && docker compose version
```

## 2. 코드 받기
```bash
mkdir -p /opt/blog && cd /opt/blog
git clone -b develop https://github.com/ldw9571/blog-assist-program.git test
git clone -b main    https://github.com/ldw9571/blog-assist-program.git prod
cp test/deploy/{docker-compose.yml,Caddyfile,env.example,update.sh,backup.sh} .
chmod +x update.sh backup.sh
cp env.example .env
openssl rand -base64 32   # 두 번 실행해서 PROD_APP_SECRET, TEST_APP_SECRET 에 각각 넣기
vi .env                   # 값 채우기
chmod 600 .env
```

## 3. 프로그램 실행 (운영 + 테스트 + DuckDNS)
```bash
cd /opt/blog
docker compose up -d --build      # 처음엔 빌드로 3~5분
docker compose ps                 # blog-prod, blog-test, blog-duckdns 가 Up 이면 성공
curl -sI http://127.0.0.1:8081/login | head -1   # HTTP/1.1 200 이면 운영 OK
curl -sI http://127.0.0.1:8082/login | head -1   # 테스트 OK
```

## 4. Apache 에 주소 연결 (기존 laravel 사이트는 그대로)
```bash
PROD=내이름.duckdns.org ; TEST=내이름-test.duckdns.org     # ← 실제 주소로
sed -e "s/PROD_DOMAIN/$PROD/" -e "s/TEST_DOMAIN/$TEST/" /opt/blog/test/deploy/apache/zz-blog.conf > /etc/httpd/conf.d/zz-blog.conf
setsebool -P httpd_can_network_connect 1     # SELinux: Apache → 프로그램 연결 허용
httpd -t && systemctl reload httpd
httpd -S 2>&1 | grep -A5 "VirtualHost configuration"   # laravel.local 이 맨 위(기본)인지 확인
```

## 5. 방화벽 + 공유기 포트포워딩
```bash
firewall-cmd --permanent --add-service=http --add-service=https
firewall-cmd --reload
```
공유기: 외부 80 → 서버내부IP:80, 외부 443 → 서버내부IP:443 (TCP)

## 6. HTTPS 인증서 (무료, 자동 갱신)
```bash
dnf -y install epel-release
dnf -y install certbot python3-certbot-apache mod_ssl
certbot --apache -d $PROD -d $TEST --redirect --agree-tos -m 내이메일주소
systemctl enable --now certbot-renew.timer
```
→ 휴대폰 LTE(와이파이 끄고)로 https://운영주소 접속

## 평소 사용
| 하고 싶은 것 | 명령 (/opt/blog 에서) |
|---|---|
| 테스트 서버 업데이트 (develop) | `./update.sh test` |
| 운영 서버 업데이트 (main) | `./update.sh prod` |
| 로그 보기 | `docker compose logs -f prod` (또는 test, caddy) |
| 재시작 | `docker compose restart prod` |
| 전체 끄기 / 켜기 | `docker compose down` / `docker compose up -d` |
| 백업 | `./backup.sh` (자동: `crontab -e` → `0 4 * * * /opt/blog/backup.sh`) |

## 개발 → 운영 흐름
1. PC에서 개발 → `develop` 에 push → 서버에서 `./update.sh test` → 테스트 주소에서 확인
2. 괜찮으면 GitHub에서 develop → main 합치기 (Pull Request) → 서버에서 `./update.sh prod`

## 문제 해결
- 서버가 재부팅돼도 Docker가 자동으로 다시 켜요 (restart: unless-stopped)
- 인증서 발급 실패: 공유기 80 포트포워딩, DuckDNS 주소가 집 IP를 가리키는지(`ping 주소`) 확인
- 502/503 오류: `docker compose ps` 로 프로그램이 켜져 있는지, `getsebool httpd_can_network_connect` 가 on 인지 확인
- 관리자 IP가 바뀌어 IP 제한에 막혔을 때: docker-compose.yml 의 prod environment 에 `IP_FILTER_FORCE_OFF: "true"` 추가 → `docker compose up -d prod`
