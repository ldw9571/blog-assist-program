🔑 Gemini API 키

블로그 글은 회원님 본인의 Gemini API 키로 만들어져요.

블로그 도우미를 쓰려면 먼저 API 키를 등록해 주세요. (아래 발급 방법 참고)
⚠️ 아직 등록된 키가 없어요

위에서부터 순서대로 사용해요. 한도 초과·막힘이면 다음 키로 자동으로 넘어가요.

저장할 때 실제로 작동하는 키인지 확인해요. 키는 암호화되어 저장되고, 관리자도 원문을 볼 수 없어요.
💡 예비 키는 다른 구글 계정(또는 다른 프로젝트)에서 만들어야 효과가 있어요. 같은 프로젝트의 키는 한도를 같이 써요.

최대 개수(3개)까지 등록했어요. 바꾸려면 기존 키를 삭제하고 추가하세요.

📋 API 키 발급 방법 (무료, 약 1분)
  1. 구글 AI 스튜디오 API 키 페이지에 구글 계정으로 로그인
  2. API 키 만들기(Create API key) 클릭 → 프로젝트는 새로 만들기 선택
  3. 만들어진 키를 복사해서 위 칸에 붙여넣고 등록하기
⚠️ 무료 등급은 하루·분당 사용 횟수 제한이 있어요. 한도를 넘으면 잠시 기다리거나 구글에서 결제를 연결하면 늘어나요.
⚠️ 무료 등급에서는 입력한 내용이 구글의 서비스 개선에 쓰일 수 있어요. 민감한 개인정보는 넣지 마세요.
⚠️ API 키는 비밀번호와 같아요. 다른 사람에게 알려주지 마세요.
