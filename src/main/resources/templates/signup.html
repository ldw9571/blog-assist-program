결제하신 크몽 닉네임을 적어주세요. 결제 확인에 사용해요.

블로그 글은 회원님 본인의 API 키로 만들어져요. 1번 키가 한도에 걸리면 2번, 3번 키로 자동으로 넘어가요.
다른 구글 계정(또는 다른 프로젝트)에서 만든 키여야 효과가 있어요. 같은 프로젝트의 키는 한도를 같이 써요.
가입할 때 실제로 작동하는 키인지 확인하고, 암호화해서 저장해요. 나중에 '내 정보'에서 추가·삭제할 수 있어요.

📋 API 키 발급 방법 (무료, 약 1분)
  1. 구글 AI 스튜디오 API 키 페이지에 구글 계정으로 로그인
  2. API 키 만들기(Create API key) 클릭 → 프로젝트는 새로 만들기
  3. 만들어진 키를 복사해서 위 칸에 붙여넣기

⚠️ 무료 등급은 하루·분당 사용 횟수 제한이 있고, 입력한 내용이 구글 서비스 개선에 쓰일 수 있어요.
